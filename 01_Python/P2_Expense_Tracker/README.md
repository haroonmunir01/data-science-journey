# Project 02 – Expense Tracker

## Overview

Expense Tracker is a command-line Python application designed to record and manage personal expenses.

The application allows users to add expenses, view existing expenses, search for specific expenses, edit or delete records, and manage expense categories through a simple menu-driven interface.

## Features

* Add new expenses
* View all recorded expenses
* Search expenses by description
* Edit existing expenses
* Delete expenses
* Select expenses from predefined categories
* Validate user input
* Handle invalid and empty inputs
* Case-insensitive expense searching
* Reusable functions for input validation and data collection

## Expense Information

Each expense contains:

* **Amount**
* **Description**
* **Category**

Available categories include:

* Food
* Transport
* Bills
* Shopping
* Entertainment
* Other

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* Loops
* `match/case`
* Input validation
* Exception handling

## Purpose

This project was created to practice Python programming through a practical command-line application.

It focuses on working with lists of dictionaries, creating reusable functions, handling user input, validating data, and managing program flow through loops and conditions.
