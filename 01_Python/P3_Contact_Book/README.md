# Project 03 – Contact Book

## Overview

Contact Book is a command-line Python application designed to store and manage contact information.

The application allows users to add, view, search, edit, and delete contacts through a simple menu-driven interface.

## Features

* Add new contacts
* View all contacts
* Search contacts by name
* Edit existing contact information
* Delete contacts
* Select contacts from predefined categories
* Case-insensitive name searching
* Input validation for contact information
* Phone number validation
* Email validation
* Reusable input and validation functions
* Menu-driven command-line interface

## Contact Information

Each contact contains:

* **Name**
* **Phone Number**
* **Email**
* **Category**

Available categories:

* Family
* Friend
* Work
* Other

## Technologies & Concepts Used

* Python
* Lists

* Functions
* Function arguments
* Return values
* `for` loops
* `while` loops
* `match/case`
* Conditional statements
* `enumerate()`
* String methods
* Input validation
* `try/except`
* Exception handling
* Case-insensitive searching
* Basic CRUD operations

## Purpose

This project was created to practice building a complete command-line application using core Python concepts.

It reinforces the use of lists, dictionaries, functions, loops, conditions, input validation, and CRUD operations while introducing reusable functions for handling different types of contact information.
