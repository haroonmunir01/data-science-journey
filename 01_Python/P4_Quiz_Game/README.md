# Project 04 – Programming Concepts Quiz

## Overview

Programming Concepts Quiz is a command-line Python application that tests the user's understanding of **general programming concepts** that are applicable across different programming languages.

The quiz presents multiple-choice questions, validates the user's answers, keeps track of their score, and displays the final result.

Questions are randomized each time the quiz starts.

## Features

* 10 programming concept questions
* 4 multiple-choice options for each question
* Randomized question order
* Answer validation
* Empty-input validation
* Invalid input handling
* Score tracking
* Final score display
* Quiz instructions
* Menu-driven command-line interface

## How It Works

1. The user starts the program.
2. The main menu provides options to:

   * Start the quiz
   * View instructions
   * Exit the program
3. When the quiz starts, the questions are placed into a list and randomly shuffled.
4. Each question displays four possible answers.
5. The user enters the number corresponding to their answer.
6. The program validates the input.
7. The selected answer is compared with the correct answer.
8. The score is updated for every correct answer.
9. After all questions are completed, the final score is displayed.
