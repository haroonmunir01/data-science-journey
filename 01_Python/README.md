# Python

This folder documents my Python journey through hands-on projects instead of chapter-based exercises.

Each project is designed to solve a real-world problem while strengthening my understanding of Python fundamentals, problem-solving, and software development practices.

## Learning Approach

* Learn by building projects.
* Use Git to track meaningful progress.
* Refactor older projects as I learn new concepts.
* Focus on writing clean, readable, and maintainable code.
